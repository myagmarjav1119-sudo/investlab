# InvestLab — UX & Design Research

## Reference Site

https://www.chagnuur.mn — Mongolian medical e-learning platform.

## Design Patterns Observed

### Layout
- Clean white background with accent color used sparingly for CTAs and highlights
- Centered hero section with search/filter prominently placed
- Card-based grid for courses and articles
- Clear visual hierarchy: large headings, medium subheadings, readable body text
- Footer with essential links and contact info

### Navigation
- Top bar with logo, main nav links, auth buttons
- Main nav items: Нүүр, Сургалт, Статистик, Нийтлэл, etc.
- Simple horizontal menu, collapsible on mobile

### Homepage Sections (mapped to InvestLab)

1. **Hero**
   - Headline about online learning
   - Search/courses filter
   - Primary CTA button

2. **Course Categories**
   - Icon + label + count for each category
   - Horizontal row of category cards

3. **Featured Courses**
   - Tab filter (featured / paid / free)
   - Course cards: image, category tags, title, duration, lesson count, CTA

4. **Why Choose Us**
   - Icon + title + description for each value prop

5. **Pricing / Plans**
   - Plan cards with price, billing period, feature list, CTA

6. **Recent Blog Posts**
   - Blog cards with image, date, title, excerpt

7. **Footer**
   - Logo, links, contact info

## Design Direction for InvestLab

- Keep the same modern, clean, card-driven layout
- Replace medical visuals with stock-market/finance visuals
- Maintain Mongolian-first content, English toggle
- Use a trustworthy primary color (deep blue or financial green)
- Keep generous whitespace and clear CTAs
- Ensure all course/pricing content is CMS-editable
